# 작품요약서
## 아파트 스마트 주차 관리 시스템 (PCS — Parking Control Sys)

---

## 1. 작품 개요

### 배경 및 필요성

아파트 주차장에서 발생하는 불법주차·무단점거 문제는 입주민 간 갈등의 주요 원인이다. 기존 방식은 관리자가 직접 순찰하며 위반 차량을 찾는 수동 방식에 의존하기 때문에 다음과 같은 문제가 있다.

- 관리자 부재 시 즉각 대응 불가
- 위반 기록이 체계적으로 남지 않음
- 입주민이 실시간 주차 현황을 파악할 방법 없음
- 주차칸 탐색에 소요되는 시간 낭비

### 목적

AI 카메라(Jetson Orin Nano)로 주차장을 24시간 자동 모니터링하여 불법주차를 즉시 감지·기록하고, 관리자와 입주민 모두가 웹 대시보드에서 실시간으로 주차 현황을 확인할 수 있는 스마트 주차 관리 시스템을 구현한다.

### 핵심 차별화 기능

단순 불법주차 감지를 넘어, AI 카메라가 수집한 주차 이용 이력을 분석하여 **입주민이 자주 사용하는 주차칸 순위와 현재 빈자리 여부를 실시간으로 제공**한다. 주차칸 탐색 시간을 줄이고 입주민 간 자리 다툼을 예방하는 예방적 기능이다.

## 2. 시스템 구성

### 전체 아키텍처

```
[Jetson Orin Nano]              [서버 (노트북)]                 [클라이언트]
  AI 카메라
  YOLOv8 추론      →   RabbitMQ (메시지 큐)   →   MySQL (데이터 저장)
  RTSP 스트림      →   MediaMTX (HLS 변환)    →   브라우저 영상 재생
                            ↕
                   Node.js Express API (포트 4000)
                            ↕
               ┌────────────────────────────┐
               │     React 웹 대시보드       │
               │  관리자(PC) / 입주민(모바일) │
               └────────────────────────────┘
```

### 기술 스택

| 영역 | 기술 |
|------|------|
| AI / 하드웨어 | Jetson Orin Nano, Python, YOLOv8, OpenCV |
| 스트리밍 | MediaMTX (RTSP → HLS), hls.js |
| 메시지 큐 | RabbitMQ |
| 데이터베이스 | MySQL |
| 백엔드 | Node.js, Express v4, REST API, SSE |
| 프론트엔드 | React, TypeScript, Vite, Tailwind CSS |
| 인증 | Lumi 플랫폼 |
| 인프라 | Docker Compose |

## 3. 상세 내용

### 3-1. 관리자 화면

관리자 화면은 **Dark Command 테마**(다크 네이비)로 설계된 데스크탑 최적화 대시보드이다. 좌측 사이드바에서 5개 메뉴로 이동한다.

---

#### ① 관리자 대시보드

> **실시간 주차 현황·위반·시스템 상태를 한눈에 파악**

상단 4개 통계 카드:

| 카드 | 표시 내용 | 색상 |
|------|-----------|------|
| 주차 현황 | 전체 3칸 중 1칸 점유 (점유율 33%) | 파랑 |
| 미처리 위반 | 0건 (이상 없음) | 빨강 |
| CCTV | 1대 (온라인 0 / 오프라인 1) | 청록 |
| 방문자 대기 | 0건 (대기 없음) | 초록 |

하단 2개 패널:
- **최근 위반 (Recent Alerts)**: AI가 감지한 불법주차 위반 목록 실시간 표시. 현재 "아직 위반 없음 — 정상"
- **시스템 상태 (System Status)**: 백엔드 API · MySQL DB · RabbitMQ · AI 서비스 · 카메라 각각의 ONLINE/OFFLINE 상태 표시

우측 상단에 현재 시각(LIVE)이 실시간으로 표시된다. **30초마다 자동 갱신**.

---

#### ② CCTV 모니터링

> **주차장 카메라 영상을 브라우저에서 실시간 재생**

- Jetson Orin Nano가 RTSP로 전송하는 스트림을 MediaMTX가 HLS로 변환, `hls.js`로 브라우저에서 재생
- 카메라 카드 클릭 시 전체화면 모달로 확대 가능
- 온라인/오프라인 카메라 수 우측 상단에 표시
- 현재 등록된 카메라: Gate LPR Camera (GATE동 지하)

---

#### ③ 불법 주차 관리

> **AI가 감지한 불법주차 위반 목록 관리 및 처리**

- SSE(Server-Sent Events)로 위반 발생 시 5초 이내 실시간 알림 수신
- SSE 연결 실패 시 30초 폴링으로 자동 fallback
- 각 위반 건에 대해 **처리 완료** 버튼으로 조치 기록
- 현재 화면: "불법 주차 위반 없음" (정상 상태)

---

#### ④ 회원 관리

> **입주민 계정 목록 조회 및 검색**

- 전체 3명 (입주민 3 · 관리자 0)
- 등록된 입주민: 김근영(101동 201호), 정문영(101동 305호), 박지민(102동 101호)
- 이름 · 전화번호 · 이메일로 실시간 검색 가능
- 각 입주민의 역할 · 연락처 · 이메일 · 호수 · 차량 수 표시

---

#### ⑤ 방문자 승인

> **입주민이 등록한 방문자 출입증을 관리자가 승인/거절**

- 현재 대기 3건
- 각 카드에 방문자 이름 · 차량번호 · 방문 목적 · 방문 날짜 · 방문 시간 · 만료 시각 표시
- **승인** (초록) / **거절** (빨강) 버튼으로 즉시 처리
- 등록된 방문자: 이동욱(택배 수령), 이광수(이사 도움), 이영찬(가족 방문)

---

#### ⑥ 주차 제어

> **장난감 차 색깔 기반 입출차 제어 + 입주민 알림 자동 발송**

물리 모형(장난감 차 3대: 빨강·파랑·회색)에 맞춘 수동 입출차 제어 기능.

**입차 패널**: 색깔 버튼(🔴 빨간 차 / 🔵 파란 차 / ⬜ 회색 차) 클릭 → 해당 입주민 차량 자동 매핑
- 빨간 차 → 김근영(12가3456), 파란 차 → 정문영(34나5678), 회색 차 → 박지민(56다9012)
- 입차 즉시 해당 입주민에게 "빈자리 + 선호 주차칸" 알림 자동 발송

**주차칸 현황 그리드**: AI 카메라 기준 점유 상태 실시간 표시 (5초 갱신)
- AI 칸 확정 후 해당 칸 카드에 "🔴 빨간 차 출차" 버튼 표시
- 출차 클릭 → 입주민 앱에 주차칸 비워짐 알림 발송

**금지구역**: 점유 감지 시 출차 버튼 표시 (불법주차 위반 처리)

### 3-2. 입주민 화면

입주민 화면은 **모바일 최적화** UI로, 하단 탭 바(홈 · 내 차량 · 주차 이력 · 방문자 · 설정)로 구성된다.

---

#### ① 입주민 홈

> **실시간 주차 현황과 내 선호 주차칸을 한 화면에서 확인**

**실시간 주차 현황 카드**
- 전체 3칸 · 주차 중 1칸 · 빈자리 2칸 · 점유율 33%
- **10초마다 자동 갱신**

**내 선호 주차칸 카드** ← 차별화 핵심 기능
- 이용 이력 분석 기반 순위
  - 🥇 1위: A1-001 (40%) — **현재 사용 중** 🔴
  - 🥈 2위: A1-003 (40%) — **현재 비어있음** 🟢
- 최근 총 15회 이용 기록 기반
- 빈자리 여부 **실시간 반영** (10초 폴링)

**빠른 메뉴**: 내 차량(파랑), 주차 위치(보라)

**공지사항**: 관리자가 등록한 공지 표시

---

#### ② 입주민 내 차량

> **현재 주차 위치와 주차칸 분석을 한 화면에서 확인**

- 현재 주차 위치: **A1-001** (A동 지상)
- 차량 번호: **12가3456**

**주차 정보**
- 구역: A동 지상
- 위치 번호: 15
- 입차 시간: 5월 10일 오후 06:16
- 주차 시간: 2시간 15분 (경과 시간 실시간 표시)

**주차칸 분석**
- 🥇 1위: A1-001 (40%) — 현재 사용 중 🔴
- 🥈 2위: A1-003 (40%) — 현재 비어있음 🟢

#### ③ 입주민 주차 이력

> **완료된 주차 세션 이력과 통계를 날짜별로 조회**

**통계 카드 3개**:
- 총 이용 횟수 / 평균 주차 시간 / 최애 주차칸

**이번 달 누적 시간**: 해당 월 주차 시간 합산 (CalendarDays 아이콘)

#### ④ 입주민 방문자 관리

> **방문자 출입증 등록 및 현재 상태 확인**

**방문자 목록**: 각 카드에 이름 · 목적 · 상태 뱃지 (🟡 승인 대기 / 🟢 승인됨 / 🔴 거절됨) · 방문 날짜/시간/차량번호

**+ 버튼 → 바텀시트 모달 등록 폼**:
- 방문자 이름 (필수), 차량 번호 (선택), 방문 날짜 (필수), 방문 시간대 (선택), 방문 목적 (선택)

## 5. 핵심 기능 상세 — 선호 주차칸 분석

이 시스템의 가장 큰 차별화 기능. AI 카메라가 쌓은 데이터를 분석하여 입주민에게 최적 주차 위치를 추천한다.

### 동작 원리

```
① AI 카메라가 차량 번호판을 인식하고 어느 주차칸에 주차했는지 기록
         ↓
② spot_status_logs 테이블에 차량번호 + 주차칸 + 시각 누적 저장
         ↓
③ /parking/spot-preference API 호출 시 3-way JOIN으로 집계
   - 해당 차량이 어느 칸에 몇 번 주차했는지 카운트
   - 비활성 칸·금지구역 제외
   - 각 칸의 현재 빈자리 여부 실시간 조회
         ↓
④ 이용 빈도 순위 TOP 5 반환 → UI에서 상위 2개 표시
```

### 응답 예시

```json
{
  "preferred_spots": [
    { "spot_id": "A1-001", "visit_count": 6, "percentage": 40, "is_available": false },
    { "spot_id": "A1-003", "visit_count": 6, "percentage": 40, "is_available": true }
  ],
  "total_visits": 15
}
```
